# Hashing Implementation

This directory contains implementations related to Hashing and Hash Tables.

## Overview
Hashing is a technique to convert a range of key values into a range of indexes of an array. It is used to facilitate the next level of searching method when we have a large number of data elements.

## Contents
- **Assignments**:
  - `data assignment 5`: folder containing assignment solutions.
  - `task1.cpp`: Implementation of hash functions/tables (Task-based).
  - `task2.cpp`: Collision resolution strategies.

## Key Concepts
- **Hash Function**: Maps keys to indices.
- **Collision Resolution**: Handling cases where two keys map to the same index (e.g., Chaining, Open Addressing).
