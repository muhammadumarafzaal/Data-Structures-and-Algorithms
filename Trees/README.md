# General Trees

This directory contains C++ implementations and algorithms for General and Binary Trees.

## Overview
A Tree is a non-linear hierarchical data structure consisting of nodes connected by edges.

## Contents
- **Basic Operations**:
  - `height of binary tree.cpp`: Calculate tree height.
  - `count leaf.cpp`: Count leaf nodes.
  - `size of tree.cpp`: Total number of nodes.

- **Traversals**:
  - `level order traversal.cpp`: BFS traversal.
  - `left view binary tree.cpp` / `right view binary tree.cpp`: View-based traversals.
  - `level order traversal in spiral form.cpp`: Spiral BFS.

- **Checks & Properties**:
  - `check balance tree.cpp`: Check if tree is balanced.
  - `check if two nodes are cousin.cpp`: Cousin verification.
  - `identical trees.cpp`: Check if two trees are identical.
  - `mirror tree.cpp`: Convert tree to its mirror.

## Usage
Compile any specific file:
```sh
g++ "level order traversal.cpp" -o levelorder
./levelorder
```
