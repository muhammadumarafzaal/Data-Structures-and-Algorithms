# Linked List Implementation

This directory contains C++ implementations of Linked List data structures.

## Overview
A Linked List is a linear data structure where elements are not stored at contiguous memory locations. The elements in a linked list are linked using pointers as shown in the below image:
[Data] -> [Data] -> [Data] -> NULL

## Contents
- **Basic Operations**:
  - `Insertion at head.cpp`: Logic for inserting nodes at the beginning.
  - `Insertion at tail.cpp`: Logic for appending nodes.
  - `InsertionatMiddle.cpp`: Inserting nodes at specific positions.
  - `node implementation.cpp`: Basic structure of a node.
  
- **Advanced Types**:
  - `singly circular linked list.cpp`: Implementation of a circular linked list.
  - `singly linked list complete.cpp`: Comprehensive singly linked list operations.

- **Algorithms**:
  - `sorting .cpp`: Sorting algorithms applied to linked lists.

## Usage
Compile any `.cpp` file using a C++ compiler (e.g., g++):
```sh
g++ "singly linked list complete.cpp" -o linkedlist
./linkedlist
```
