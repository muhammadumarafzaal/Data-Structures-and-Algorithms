# Binary Tree Implementation

This directory contains C++ implementations focused specifically on Binary Trees and Binary Search Trees (BST).

## Overview
A **Binary Tree** is a tree data structure in which each node has at most two children, which are referred to as the left child and the right child.

## Contents
- **Implementation**:
  - `BinaryTree implementation method1.cpp`: Basic implementation.
  - `tree basics.cpp`: Comprehensive operations.
  - `Deletion Implementation.cpp`: Node deletion logic.

- **Traversals**:
  - `post order traversal.cpp`: Post-order DFS.
  - `traversals without recursion.cpp`: Iterative traversals.
  - `vertical traversal.cpp`: Column-wise traversal.
  - `Digonal traversal.cpp`: Diagonal traversal.

- **Construction**:
  - `contructing tree from inpre order.cpp`: Building a tree from Inorder and Preorder arrays.

## Usage
Compile the basics file:
```sh
g++ "tree basics.cpp" -o treebasics
./treebasics
```
