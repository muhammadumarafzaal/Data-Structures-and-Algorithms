# Stack Data Structure

This directory contains C++ implementations and practice problems for the Stack data structure.

## Overview
A Stack is a linear data structure which follows a particular order in which the operations are performed. The order may be LIFO (Last In First Out) or FILO (First In Last Out).

## Contents
Located in `Stack practice/`:
- **Core Implementation**:
  - `task 1.cpp`: Basic stack operations.
  - `task 3.cpp`, `task 5 pointer based.cpp`: Pointer/Array based stack tasks.

- **Assignments**:
  - `DATA ASSIGNMENT 2`: Subfolder with assignment specific code.

## Key Operations
- **Push**: Adds an item in the stack.
- **Pop**: Removes an item from the stack.
- **Peek/Top**: Returns the top element without removing it.

## Usage
Navigate and compile:
```sh
cd "Stack practice"
g++ "task 1.cpp" -o stack_task
./stack_task
```
