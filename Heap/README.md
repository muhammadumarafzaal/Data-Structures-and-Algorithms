# Heap Data Structure

This directory contains C++ implementations of Heap data structures.

## Overview
A Heap is a special Tree-based data structure in which the tree is a complete binary tree. It is commonly used to implement Priority Queues.

## Contents
- `heap.cpp`: Core implementation of Max-Heap/Min-Heap operations (Insert, Delete, Heapify).
- `heapprac.cpp`: Practice problems and usage examples.
- `f233106_T1.cpp`: Assignment submission related to heaps.

## Key Operations
- **Insert**: Adds a new element while maintaining the heap property.
- **Extract Max/Min**: Removes and returns the root element.
- **Heap Sort**: Sorting elements using heap properties.

## Usage
Compile the main file:
```sh
g++ "heap.cpp" -o heap
./heap
```
