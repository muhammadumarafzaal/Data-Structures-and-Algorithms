# Binary Search Tree Data Structure

This branch contains Binary Search Tree (BST) implementations.

## What is a Binary Search Tree?
A Binary Search Tree is a binary tree where each node has at most two children, and the left child is less than the parent, and the right child is greater than the parent.

## Features:
- Efficient searching
- O(log n) average case for search, insert, and delete
- Ordered traversal
